# Вівчарик — orders/checkout/payments/delivery/fiscal/wholesale (condensed)

Scope: Ukraine only (international quote path dormant, keep enum AWAITING_QUOTE). No forms on site; Leads removed.
Cart: server cart (token cookie, locale, currency, couponCode, 30d); CartItem variantId + quantityMilli (PIECE/KG/SKEIN/METRE); drawer only, no qty stepper; sold-out lines greyed excluded; custom-size lines qty 1, price recomputed on server (rate/m², loom bounds); made-to-order = full prepay, no COD; custom-size capacity 5 → honest «Виготовлення до [дата]», owner pause; mixed cart one order, card only, full prepay, ships after 14 days, no split. Reservation 30 min at checkout (one-of-one from add-to-cart); sweep every minute; unpaid keep stock 3 days. No abandoned-cart email, no wishlist server, no gift wrap/certificates/instalments.
Checkout one page Contact→Delivery→Payment→Summary. Name «Прізвище та ім'я (як у паспорті)» ≥2 words, split surname/first (admin can fix before waybill); patronymic optional (conflict: required for Ukrposhta/COD). Phone required, E.164 normalise. Email optional except custom-size, company, international, non-uk. «Я юридична особа» → company name + ЄДРПОУ → IBAN invoice «без ПДВ». Delivery fields per carrier (NP city directory, branch/locker ref, street/house/flat, 5-digit postcode Ukrposhta). No order comment. Terms checkbox. «Запам'ятати» browser-only. Promo code collapsed. Button states amount now: card «Оплатити {total}», COD «Оплатити доставку {both legs}», prepayment «Оплатити передоплату 460 ₴», IBAN «Отримати рахунок». Attribution (utm, referrer, from=card). Locales uk/en/pl/de; non-uk show EUR (NBU daily), charge currency pending WayForPay V11.
Delivery: NP branch (list+map), NP locker (only if parcel fits — packed dims per variant), NP courier, Ukrposhta, pickup Яворів free. Carrier enum NOVA_POSHTA|UKRPOSHTA|PICKUP|INTERNATIONAL; npWarehouseRef + address snapshot; NP key server-side proxy with cache/nightly sync/circuit breaker. Dispatch «за 2–4 дні»; transit NP 1–3, UP 3–7 days. Price computed server-side (NP live, UP tariff table) — tariffs are unresolved tokens; buyer pays shipping; OPEN: is shipping collected by site or paid to carrier? Waybills auto in panel, weight/volume prefilled, number → tracking + event, unlocks PACKING→SHIPPED, 100×100 label, batch create/print; UP same. Tracking poll 30 min → DELIVERED auto.
Payments (server-derived availableMethods, twice): CARD_ONLINE (WayForPay + Apple/Google Pay, widget/redirect; OFF until ПРРО registered; failed → retry/change method), COD «з оглядом» (stocked only; buyer pays both shipping legs online: shippingForwardMinor + shippingReturnDepositMinor; codAmount = subtotal − discount − deposit; deposit credited exactly once on DELIVERED; refusal → RETURNED; waive deposit ⚠ with reason), partial prepayment min(max(round(subtotal×10%), 46000), total) kopiykas (setting), balance COD; BANK_TRANSFER IBAN (PENDING/UNPAID + invoice PDF, manual reconcile). Never personal card transfer.
Statuses: OrderStatus AWAITING_QUOTE(dormant)·PENDING·CONFIRMED·IN_PRODUCTION·PACKING·SHIPPED·DELIVERED·CANCELLED·RETURNED; PaymentStatus UNPAID·AUTHORIZED(prepayment)·PAID·PARTIALLY_REFUNDED·REFUNDED·FAILED. Transitions: PENDING→CONFIRMED (paid/COD/prepayment reconciled; stock decremented); CONFIRMED→IN_PRODUCTION auto if custom line (expectedDispatchAt = next working day after +14d); →PACKING needs «Підтверджено дзвінком» (confirmedByCallAt/By); PACKING→SHIPPED needs tracking; SHIPPED→DELIVERED manual/carrier (COD deposit credited); any except DELIVERED→CANCELLED reason required, stock back, refund prompt; DELIVERED→RETURNED within 14 days. Only legal transitions offered; OrderEvent + audit. Jobs: autoCancelUnpaid 3 days (card); unconfirmedReminder 24h Telegram; productionDueSoon amber 3 days/red. Webhook race: stock gone at payment → auto refund + cancel. Buyer labels: Прийнято · Оплачено · Виготовляється · Пакується · Відправлено + ТТН · Доставлено.
Order number VCH-{YY}-{NNNN}. guestToken → /{locale}/order/{guestToken} (lines, totals, payment line, «Що далі», dispatch date, COD arithmetic, phones). Lookup by number+phone → status only. Cancel/address change/returns by phone only. Pay link /order/{guestToken}/pay (for staff-created quick orders).
Fiscal (R14): WayForPay built-in ПРРО (fallback own ДПС ПРРО). Receipts: card always; prepayment own receipt (isPrepayment), rest by NP; IBAN none (invoice + delivery note); shipping not on receipt; refunds/cancel after pay → return receipt. Content: line name (name,size,colour), SKU, qty, price, «Знижка» line, legal seller name, address, uk, «Без ПДВ», order no. FiscalReceipt {kind SALE|RETURN, status PENDING|ISSUED|FAILED, amount, provider, providerId, fiscalCode, receiptUrl, isPrepayment, qrPayload, pdfUrl, lastError, issuedAt}, keep 3 years. Auto after payment; retry 5 min; Telegram after 1h. Shown only on order page (card states pending poll 3s×60s / issued with QR, PDF, «Перевірити в податковій» / late / prepayment / return). Emails: no receipt except refund. Admin badge + «Повторити» Owner/Admin; monthly Excel. Public GET /orders/{guestToken}/receipts.
Refunds: payments.refund Owner/Admin; card → same card; COD/IBAN → buyer IBAN taken in call; WayForPay refund API unverified (manual fallback). Returns 14 days, change-of-mind shipping by buyer, custom only defects; exchange = return + new order; no returns module (RETURNED + notes).
Buyer emails (no-reply@, Reply-To, order locale, both phones, legal footer): confirmation (order link), shipped (ТТН), cancelled (incl. auto), refund («Кошти повернено» + return receipt link), review request 7 days after DELIVERED (opt-out, site + «Оцінити в Google»), invoice PDF for IBAN/company. No SMS; messengers manual.
Wholesale: automatic volume tiers 5 pcs −10%, 25 pcs −20% across order (excl. by-weight & custom), no stacking with promo (larger wins), snapshot discountSource=VOLUME, volumeTierPercent; nudge in cart (removed from drawer R10); companies tick «Я юридична особа», IBAN invoice + delivery note; else phone/messenger → staff creates order. No price list/form.
Promotion {code case-insensitive, PERCENTAGE|FIXED|FREE_SHIPPING|BUNDLE, value, minSubtotal, usage & per-customer limits, product/category scope, dates, active}; one per order; reason on failure; revalidated at creation; snapshot. Per-product sale. FREE_SHIPPING vs buyer-pays conflict.
Customers: no accounts; Customer derived from orders (email, phone, name, locale, acceptsMarketing), admin «Клієнти» read-only (lifetime orders, value, AOV, returns/cancellations), join by email AND phone; only edits: fix name/phone/locale, consent, anonymise. Quick order «Купити в 1 клік» {phone E.164 UA, product, variant, qty, sourcePath, assignedTo; NEW→CALLED→CONVERTED/DECLINED/SPAM; orderId on convert; uk only, stocked; purge 8 months}.
Admin order actions: cards list, filters, saved views (Потребують уваги, Очікують оплати, У виробництві, До відправки сьогодні, Проблемні), «Подзвонити» tel + confirmation-call checkbox, payment reconciliation queue (manual_bank, cod_settlement, partial; value date + reference required; idempotent), mixed «чекає на полиці», internalNote + threaded notes, assigned manager filter (no field yet), no editing except name split/address/branch change logged, no split, export ⚠, weekly report, receipts Excel, Telegram new order w/o personal data. Stock «Продано в магазині», «Продано на Prom».
Boundary: site→panel: cart ops/reservations, idempotent order creation with full line snapshots (sku, name, options, image, unit price, pricing unit, quantityMilli, customSpec), locale, contact, delivery (npWarehouseRef + snapshot), method, discounts, COD/deposit/prepayment figures, attribution, company, consent; quick orders; payment init. site←panel: payment methods, shipping options/prices (NP proxy), promo validation, tiers, custom-size price/bounds, stock/availability, public settings (prepayment floor, EUR rate, capacity, card enabled), guest order page (status labels, timeline, ТТН, lines, totals, dispatch date, pay-now/at-post arithmetic, receipts), status lookup. Webhooks: WayForPay service URL authoritative (signature, idempotent, no downgrade, <5s, nightly reconciliation), NP webhook/poll, email bounce. Polling only.
Schema gaps: email nullable, company+ЄДРПОУ, prepayment amount, expectedDispatchAt, order assignee, delivery sub-type, customer by phone, public receipts endpoint. Unresolved: tariffs, free shipping threshold, COD ceiling/review threshold, LEGAL_ID, WayForPay V6–V15.
