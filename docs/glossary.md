# Словник ONEKNIGHT

Одне слово — одне поняття. Спірні слова вирішує власник (G99). Використовувати однаково в панелі, на сайті, у Telegram і документах.

| Слово | Що означає | Не писати |
| --- | --- | --- |
| **ONEKNIGHT** | Продукт і компанія. Завжди великими літерами | OneKnight, Oneknight |
| **Панель ONEKNIGHT**, «панель» | Інтерфейс, у якому працює бізнес (`/app`) | кабінет, адмінка (для клієнта) |
| **Бізнес** | Організація в ONEKNIGHT (один акаунт може мати кілька бізнесів) | компанія, організація |
| **Клієнт** | Людина, яка купує в бізнесу (розділ «Клієнти» в панелі) | покупець, замовник |
| **Бізнеси** (в адмінці) | Список бізнесів, які користуються ONEKNIGHT | клієнти (щоб не плутати) |
| **Власник** | Людина, яка створила бізнес і має всі права | адміністратор |
| **Команда** | Люди бізнесу з доступом до панелі (менеджер, маркетолог, комплектувальник) | співробітники, юзери |
| **Замовлення** | Покупка клієнта з будь-якого джерела | заявка (заявка — це запит на послугу ONEKNIGHT) |
| **Заявка** | Запит на послугу ONEKNIGHT (сайт, SEO…) з сайту oneknight.pro | лід |
| **ТТН** | Документ доставки Нової пошти й Укрпошти | накладна (накладна — документ для клієнта), декларація |
| **Видаткова накладна** | Документ продажу для клієнта | ТТН |
| **Модуль** | Платна можливість, яку підключають у «Модулях» | плагін, розширення, аддон |
| **Інтеграція** | Доступ до зовнішнього сервісу (ключ, токен) у «Бізнес → Інтеграції» | підключення, конектор |
| **Сайт** | Сайт бізнесу, підключений до ONEKNIGHT через `ok.js` і ключ сайту | магазин, лендінг |
| **Оплата** | Розділ з підпискою ONEKNIGHT і гаманцем | білінг |
| **Гаманець** | Баланс людини, з якого оплачуються її бізнеси | рахунок (рахунок — банківський) |
| **Пробний період** | Безкоштовний період (30 днів без сайту, 3 місяці із сайтом) | тріал |
| **Пільгові дні** | 5 днів роботи після невдалого продовження | грейс |
| **Видалити** | Лише безповоротна дія | — |
| **В архів / Прибрати / Вимкнути** | Зворотні дії | видалити |
